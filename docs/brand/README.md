# Brand assets

Source files for the Construction Risk Expert (CRE) logo and icons. Copy them
to where they are used; do not edit or redraw them.

| File | Size | Use |
| --- | --- | --- |
| `brand-sheet.png` | 1536 × 1024 | Original brand sheet. Source of the files below. |
| `cre-logo-full.png` | 998 × 486, transparent | Mark + wordmark + tagline. Auth pages, PDF report header. |
| `cre-logo-mark.png` | 431 × 486, transparent | Mark only. App and admin header, mobile header. |
| `icon.png` | 512 × 512, transparent | `web/src/app/icon.png` |
| `apple-icon.png` | 180 × 180, white background | `web/src/app/apple-icon.png` |
| `favicon.ico` | 16, 32, 48 | `web/src/app/favicon.ico` |

The logos are for **light backgrounds only**: the navy parts disappear on dark
backgrounds.

Used by IO-158 (web logo, favicon, app icons) and IO-166 (PDF report header).
